# Slow SQL Access And Query

## Purpose

验证慢SQL页面的**访问面(登录即可用,无权限点)**与核心查询流程。主要防止的回归:

- 菜单/路由重新被权限闸挡住(历史上 `DM_SLOW_SQL_READ` 标签 + `CAT_DM_SLOW_SQL` 分类曾把非管理员挡在门外,2026-09-17 起权限点已彻底删除,改为登录即可用);
- 角色管理页重新出现无效的「慢SQL查询」权限项;
- 实例选择 / 时间窗 / Top 列表 / 优化建议弹窗的查询链断裂。

## Scope

- 页面:`/#/slowSql`(`frontend/src/views/slowSql/index.vue`)。
- 入口:侧边栏主菜单「慢SQL」(`utils/buildSidebarMenu.js`,条件仅 `!isDesktop`);路由无 `meta.requiredAuth`。
- 接口:`POST /console/api/slowSql/listInstances`、`/listTopSqls`、`/sqlAdvice`(后端 `SlowSqlController`,三端点均 `@RequestAuth(strategy = Ignore)`,即**仅要求登录**)。
- 不覆盖:腾讯云凭据配置页(见 `tests/frontend/system/` 偏好配置相关文档)、DBbrain 上游限流行为。

## Preconditions

- 后端 8222 运行,前端 8080 dev 或已构建产物;Chrome 已登录(账号角色见 Test Data)。
- 至少一个数据源在数据源配置中填写了 `tencentCloudInstanceId` / `tencentCloudRegion`(否则实例下拉为空,仅能执行 S4 空态场景)。
- 根账号偏好中已配置腾讯云 SecretId/SecretKey,且对应实例在时间窗内存在真实慢日志(本地/测试环境)。
- 桌面客户端(isDesktop)场景默认跳过,见 Skip Conditions。

## Test Data

- **非管理员账号**:任意普通角色子账号(如 Developers),用于验证无权限点下的可见与可查;无需任何特殊授权。
- **管理员账号**:Manager 角色,对照验证。
- 角色管理页检查:确认权限编辑树中**不存在**「慢SQL / 慢SQL查询」分类与权限项(存量账号已授的旧标签为孤儿值,不显示)。
- 查询数据为只读:不创建/修改业务数据;时间窗必须 < 7 天(后端硬校验)。

## Suites

### S1 Smoke · 菜单与路由可达(非管理员)

- 风险/目的:权限闸回归会把非管理员挡在页面外。优先级 P0。
- 初始状态:非管理员账号已登录,位于任意主页面。
- 步骤:
  1. 观察侧边栏主菜单存在「慢SQL」入口;
  2. 点击进入,或直接在地址栏访问 `/#/slowSql`;
  3. 等待页面加载完成。
- 预期:侧边栏出现「慢SQL」;URL 变为 `/#/slowSql` 且**不发生重定向**;页面渲染实例下拉、时间范围选择、快捷时间下拉、库名过滤输入框与查询按钮;浏览器控制台与接口无 406/403。
- 对照:管理员账号重复步骤 1-3,结果一致。
- 恢复:无。

### S2 Main Flow · 实例 + 时间窗查询 Top 列表

- 风险/目的:核心查询链(实例→时间窗→列表→排序/过滤/分页)。优先级 P0。
- 初始状态:S1 页面。
- 步骤:
  1. 实例下拉选择已配置云映射的数据源;
  2. 快捷时间选择「1 小时」(或手工时间范围选择 < 7 天的窗口);
  3. 点击「查询」;
  4. 观察表格:SQL 模板 / 库名 / 执行次数 / 总耗时等列;
  5. 点击「执行次数」列头切换升/降序;库名过滤框输入一个真实库名后回车;
  6. 行数超过单页上限时翻页。
- 预期:查询后表格出现慢SQL行(无慢日志时为空表而非报错);排序切换后行序变化;库名过滤后仅剩余匹配行或空表;分页控件与总行数一致;SQL 模板列的复制按钮可复制全文。
- 恢复:无(只读)。

### S3 Main Flow · 优化建议弹窗

- 风险/目的:`sqlAdvice` 结果渲染(索引建议/成本对比/备注/无需优化态)。优先级 P1。
- 初始状态:S2 查询结果非空。
- 步骤:
  1. 点击某行「优化建议」;
  2. 观察 720 宽弹窗内容;
  3. 对索引 SQL 点击「复制」。
- 预期:弹窗打开;有建议时展示索引 SQL 列表、成本对比(优化前/优化后/节约比例)与备注;无建议时展示「无需优化」文案; degraded(上游返回异常 JSON)时备注区有内容且弹窗不报错;复制按钮生效。
- 恢复:关闭弹窗。

### S4 Boundaries And Failure · 空实例 / 超窗 / 登录失效

- 风险/目的:边界与失败的可见反馈。优先级 P1。
- 步骤与预期:
  1. 使用**未配置**任何云实例映射的环境(或临时清空过滤):实例下拉为空,页面展示实例空态提示文案,查询按钮不产生请求报错;
  2. 手工时间范围选择跨度 ≥ 7 天并查询:后端拒绝,页面经统一错误队列弹出错误提示(不白屏);
  3. 退出登录后直接访问 `/#/slowSql`:跳转登录页,不泄露数据。
- 恢复:重新登录;时间范围恢复 < 7 天。

### S5 Permission · 权限模型回归

- 风险/目的:确认权限点删除后的最终形态,防止僵尸权限或漏删闸。优先级 P1。
- 步骤:
  1. 管理员进入 角色管理 → 编辑任意角色,检查权限树;
  2. 非管理员账号执行 S1/S2。
- 预期:权限树中无「慢SQL」分类与「慢SQL查询」项;非管理员全流程可用;接口响应不因角色差异而变化。
- 恢复:不修改任何角色配置。

## Cleanup

- 功能为只读查询,无业务数据清理。
- 若为 S4 修改过数据源云映射或腾讯云凭据配置,恢复原值(凭据为 secret 字段,留空提交即保持原密文)。

## Skip Conditions

- **桌面客户端(isDesktop)**:侧边栏按设计隐藏慢SQL入口,桌面场景不适用;替代验证=直接路由访问仍可用(S1 步骤 2)。
- **无云实例映射的环境**:S2/S3 跳过,仅执行 S1(预期空态)与 S4-1;原因=无上游数据源,替代验证=S4 空态断言。
- **时间窗内无真实慢日志**:S2 表格断言降级为「空表无报错」,S3 跳过;原因=上游数据不可构造(不得在生产构造负载)。
